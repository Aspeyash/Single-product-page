What's being compared

Layout is identical in both modes — same logo size, same name/status position, same stats (Followers/Rating/Reviews/Products), same Follow/Chat/Share buttons, same responsive breakpoints (desktop single row / tablet 3-column / mobile 2-row). Only the card's own background treatment and text color change:

⚪ White (pre-redesign): solid white card, drop shadow, dark text — this is how the card looked before the glass redesign shipped.

🔮 Glass (current): translucent blurred background (backdrop-filter blur + saturate), soft white border, inner highlight, white text with a subtle shadow for legibility — this is exactly what's live on the site today (v1.22.5).
